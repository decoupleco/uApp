Design philosophy

Everything in the first flight

A DeFi interface is a settlement instrument: every millisecond between user decides and pixels confirm is spread the user pays and volume the protocol loses. μi is the smallest design language that lets one engineer ship a complete, four-theme, accessible surface in one network round trip — and then grow it without ever paying a framework tax on first paint.

Every number on this page is measured and reproducible, or it is a budget with the physics that justifies it. Nothing here is a projection. A design language that invents its own evidence cannot ask a CI gate to be honest.

The budget, from physics

The first flight of a cold connection is what paints; everything after it is a second round trip. So the budget is arithmetic, not taste.

Quoted in brotli, never gzip: below ~1 KB gzip misrepresents a document by 2–3×. And bytes are not the only cost — a 13.4 KB Svelte 5 island parses and evaluates in 11.3 ms on Apple Silicon against 3.8 ms for μi's 653 B signal engine, and mid-tier Android runs 4–8× slower.

Three layers, one system

System
μi

Tokens, four themes, ~20 CSS recipes at roughly 35 B each. Always on.

Layer
Matte Glass

An optional overlay, never a theme: 323 B of static noise, blur spent only on the container in focus.

Unit
μApp

One intent, shipped as one document. Islands arrive afterwards, on gesture.

Density (Base / Sharp) is four custom properties, luminance is light-dark(), and Matte is a class — so the three axes multiply instead of forking the stylesheet.

The vocabulary

every number on this card is measured
zero
Binary-zero

No runtime dependency ships. The μApp's wallet codes its own calldata; viem is a test oracle in devDependencies.

P0
One document

Markup, CSS and the 653 B signal engine inlined: 3,792 B brotli, zero subrequests.

CLS 0
Nothing moves

Static markup matches island output and islands adopt with replaceChildren. A gate drives real Chrome and refuses to trust a zero unless every island actually loaded.

instant
Non-blocking by construction

Inline type=module is deferred, so script never blocks paint — measured: inlining four more islands moved FCP by 0 ms and only load by 172 ms.

preload
modulepreload, eager

The one chunk two islands share is fetched from <head> during the first flight; every other island waits for a gesture.

H2/H3
The flight is the budget

Measured on our own edge over HTTP/2: 9,472 B arrives in one flight, 9,728 B costs a whole round trip. QUIC's window is larger — but Pages serves no h3, so 9 KB is the number we design to.

The seven rules

enforced in CI, not in review
1
Blur is conditional

backdrop-filter:none at rest; blur(14px) only on :focus-within or .active. Never stack saturate() on it.

Matte
2
Noise is static

One inlined SVG turbulence filter at 3.5% opacity with background-attachment:local — 323 B, and fixed would repaint every scroll frame.

Matte
3
Text never floats

Every text container sits on an opaque surface token, ≥ 4.5:1 in both luminances. Translucent contrast cannot be verified at build time.

contrast
4
Color is intent

The palette is closed: --ac continue, --ok filled, --wa caution, --no reverted. One primary CTA per view, and never colour alone.

palette
5
Motion is meaning

120–180 ms ease-out, only on price change or execution state; prefers-reduced-motion disables all of it.

motion
6
Fits the flight

P0 ≤ 9 KB brotli, any later chunk ≤ 12 KB. No Tailwind preflight, no webfont, in P0.

size
7
CLS = 0

Static markup and island output have identical dimensions. Islands adopt their container — replaceChildren — they never append.

layout

Six gates run on the built artifact and the build fails on any one of them: size, contrast, palette, motion, syntax (ES2023 ESM, no CommonJS), layout — the last drives headless Chrome over the DevTools protocol and refuses to trust a zero unless every lazy island was really fetched first.

Tiering, inverted

measured on the page below

Conventional apps ship a framework first and the view second. A μApp inverts that: the view is the payload, and the framework — if a view ever needs one — arrives as a chunk that two islands share. These are the live bytes behind the demo, not a projection. P0 never contains a framework: inlining even the smallest Svelte 5 that can render this view measures 12,066 B, 31% over the budget.

Tier 1 · P0
document, CSS + JS inlined3,710 B

One file, zero subrequests, a 653 B signal engine instead of a framework. Four themes included.

Tier 2 · shared
Svelte 5 runtime chunk9,925 B

Only when a view needs components. Eagerly preloaded from <head>, because two islands share it. Built by Rollup, not Bun — 9,925 B against 13,035 B, which would not fit the 12 KB chunk budget at all. Stock Svelte: no patches into the framework.

Tier 3 · on gesture
wallet · chart · islands764 B

Wallet 764 B — no client layer, no signing library, and no ABI library: a token call is a selector plus 32-byte words, and viem stays a test oracle. Histogram 577 B · Svelte islands 332 and 2,183 B.

A cold load of the demo fetches two files beyond the document: the shared runtime, preloaded from <head>, and the histogram, which is in view on arrival. The wallet and the component islands wait for a tap, and every adoption measures CLS 0.

Matte Glass

An overlay, not a theme

Toggle Matte in the header. Cards marked for it gain a 323-byte static noise texture and a 14px blur that engages only on focus. Nothing else changes.

Focus this card

Blur costs GPU, so it is spent only on the container the user is in. Click or tab into this card with Matte enabled.

Static noise

One inlined SVG turbulence filter at 3.5% opacity, background-attachment: local. No animation, no repaint on scroll.
